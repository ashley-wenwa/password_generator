# 🔐 Password Generator

A simple Python-based CLI tool that generates strong, random passwords using letters, numbers, and special characters.

## 🚀 Features

- Customizable password length
- Includes uppercase, lowercase, digits, and symbols
- Quick and easy to use from the terminal

## 🖥️ Demo

```bash
$ python password_generator.py --length 12
Generated password: 4rT@eWz!8Qs#
```

## 📦 Requirements

- Python 3.x

Install any dependencies with:

```bash
pip install -r requirements.txt
```

## 🔧 Usage

Run the script with:

```bash
python password_generator.py --length 16
```

### Arguments:
- `--length`: Length of the password (default: 12)
